# SAW Albüm Seç — Güncelleştirme Kanalı

Bu depo yalnızca **sürüm bilgisini** (`surum.json`) ve **indirilebilir kurulum dosyalarını** (Releases)
barındırır. Uygulamanın kaynak kodu burada **değildir**.

- `surum.json` → en son sürüm, notlar ve indirme adresleri.
- Releases → her sürümün Windows (.exe) ve macOS (.tar.gz) dosyaları.

Uygulama "Hakkında → Güncelleştirmeleri Denetle" ile bu dosyayı okuyup yeni sürüm olup olmadığını anlar.
